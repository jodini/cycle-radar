# Changelog

## v0.1.0 — 2026-08-21

Initial public prototype.

- Added 20-quarter cycle timeline from 2026-Q3 through 2031-Q2.
- Separated cycle stage, action qualifier and shock overlay.
- Added narrow `OB` (Optimal Buy) and `OS` (Optimal Sell) windows.
- Added cycle predictability, typical trough-to-peak equity potential, survivability and structural risk.
- Added opportunity queue.
- Added cycle detail pages with rationale, indicators and invalidation conditions.
- Added framework / methodology documentation.
- Added LLM re-evaluation protocol and prompt generator.
- Added JSON import/export support.

### Current high-priority windows

- Luxury: `OB` around 2026-Q3.
- Chemicals: `OB` around 2026-Q4 to 2027-Q1.
- Industrial inventory: `OB` around 2026-Q4.
- Housing / building: `OB` around 2027-Q1 to Q2.

All future quarter-level timing is probabilistic and should be recalibrated quarterly.

## UI refinement

- Replaced flat `YYYY-Q#` timeline headers with two-row headers across quarterly tables: year group on top, quarter below.
- Years span the available quarter columns dynamically (full years span four quarters; partial boundary years span only the visible quarters).
